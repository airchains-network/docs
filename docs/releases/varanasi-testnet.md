# Varanasi Testnet

#### Airchains Testnet (Varanasi) - February 2025

## Airchains Varanasi Testnet Release

We are excited to introduce the Varanasi testnet, a groundbreaking advancement in Airchains' mission to build a scalable, privacy-preserving, and interoperable blockchain ecosystem. Building upon the success of Switchyard, Varanasi introduces revolutionary rollup capabilities and enhanced transaction processing features.

Varanasi represents a significant leap forward in our technology stack, introducing the Junction v0.3.2 release with comprehensive rollup module implementation. This testnet opens new possibilities for developers to create and deploy sophisticated blockchain applications with unprecedented efficiency and flexibility.

### Key Features of Varanasi:

**Advanced Rollup Module**: Varanasi introduces a sophisticated rollup module implementation, enabling efficient Layer 2 scaling solutions. The testnet showcases our commitment to solving blockchain scalability challenges through innovative rollup technology.

**Enhanced WASM Integration**: Our WebAssembly integration has been significantly improved, providing developers with a powerful and flexible environment for smart contract execution. This enhancement enables seamless cross-chain compatibility and advanced contract capabilities.

**Improved Transaction Processing**: Varanasi features enhanced transaction processing capabilities, including textual sign mode support and improved validation mechanisms. These improvements make the platform more developer-friendly and secure.

**Robust Query System**: The testnet introduces an advanced query system with total staked amount tracking and state verification mechanisms. This ensures reliable data availability and efficient state management across the network.

**Multiple Execution Environments**: Building on Switchyard's foundation, Varanasi continues to support various execution environments, including EVM, SVM, and CosmWasm, providing developers with the flexibility to choose the best environment for their applications.

### Getting Started with Varanasi:

**Documentation**: Explore our comprehensive documentation to learn about Varanasi's architecture, features, and how to build on our platform. Visit our [documentation](https://docs.airchains.org) to get started.

**Developer Resources**: Access our extensive developer resources, including tutorials, code samples, and API references. Our [developer portal](https://github.com/airchains-network) provides everything you need to start building on Varanasi.

**Community Support**: Join our growing community on [Discord](https://discord.gg/airchains) to connect with other developers, share ideas, and get support as you build on Varanasi.

We invite you to join us in this exciting new phase of blockchain innovation. Together, let's build the future of decentralized applications on Varanasi!
