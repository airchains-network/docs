# Varanasi Testnet

#### Airchains Testnet (Varanasi) - April 2025

## Varanasi Testnet Release Announcement

We are thrilled to announce the launch of the Varanasi Testnet, a transformative milestone in Airchains’ journey to deliver a streamlined, privacy-centric, and scalable blockchain ecosystem. Powered by [Junction v0.3.2](https://github.com/airchains-network/junction/releases/tag/v0.3.2), Varanasi Testnet is laser-focused on integrating Fully Homomorphic Encryption (FHE) through fhEVM rollups, eliminating unnecessary components to create a clean, efficient, and developer-friendly environment.
Varanasi Testnet redefines our approach by prioritizing FHE-based rollups and removing extraneous virtual machines (VMs) and components that cluttered previous iterations. This release is designed to empower developers and innovators to build privacy-preserving decentralized applications (dApps) with unparalleled efficiency and security.

### Key Features of Varanasi Testnet

#### 1. FHE-Powered fhEVM Rollups

Privacy by Design: Leverage Fully Homomorphic Encryption (FHE) within the fhEVM to enable secure, privacy-preserving computations on encrypted data.
Optimized Rollup Framework: Streamlined rollup architecture tailored for fhEVM, ensuring fast transaction processing and efficient scaling for privacy-focused dApps.

#### 2. Streamlined Ecosystem

Removal of Unnecessary VMs: Eliminated support for extraneous execution environments (e.g., EVM, SVM) to reduce complexity and focus exclusively on fhEVM-based workflows.
Decluttered Architecture: Simplified settlement and coordination layers to enhance performance and developer experience, making it easier to build and deploy FHE-based applications.

#### 3. Decentralized Sequencer Network

Efficient Transaction Ordering: A network of decentralized sequencers ensures reliable and rapid transaction processing, optimized for FHE rollups.
Foundation for Decentralization: Varanasi operates with a trusted sequencer set, setting the stage for a fully decentralized network in future releases.

#### 4. Robust Settlement Layer

Secure Transaction Finality: The Junction settlement layer provides trustless finality for fhEVM rollups, ensuring security and reliability for all transactions.
Validator Enhancements: Upgraded validator system with democratic governance and optimized performance, tailored for the FHE ecosystem.

#### 5. Seamless Data Availability Integration

Scalable Data Storage: Integration with leading data availability (DA) layers like EigenDA, Celestia DA, and Avail DA to support the scalability needs of FHE-based rollups.
Cost-Efficient Data Management: Optimized protocols reduce data storage costs while maintaining high performance for privacy-preserving dApps.

### Why Varanasi Testnet Matters

Varanasi Testnet marks a bold shift toward a privacy-first blockchain ecosystem. By focusing exclusively on FHE and fhEVM rollups, we’ve removed redundant components to deliver a cleaner, more efficient platform. This release empowers developers to:

- Build dApps that process encrypted data without compromising privacy.
- Leverage FHE’s potential for use cases like private DeFi, secure voting, and confidential data analytics.
- Experiment in a simplified environment designed for rapid development and deployment.
